# Required JSON Keys

Fail a workflow when required top-level JSON keys are missing.

Generated by MiniMindsLab 02.13 GitHub Action Factory.

## Usage

```yaml
- uses: ./path-to-action
  id: miniminds
  with:
    payload: '{"value":{"name":"demo","version":"1.0.0"},"required":["name","version"]}'
- run: echo '${{ steps.miniminds.outputs.result }}'
```

Runtime: Node 24. No external dependencies. No network access.
